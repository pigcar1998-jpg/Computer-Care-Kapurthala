COMPUTER CARE ACADEMY — EXCEL IMPORT MASTER GUIDE
===================================================

HOW TO IMPORT DATA:
1. Open any page (Students, Reports, etc.)
2. Click the green "📥 Import Excel" button
3. Drop your .xlsx file or browse for it
4. Wait for the import to complete

SHEET NAMES (must be exact):
- Students
- Teachers
- Fees
- Salary
- Topics
- Tasks
- Internships
- Courses
- Notifications

MATCHING RULES:
- Students matched by Mobile number (updates existing, adds new)
- Teachers matched by Name or Mobile (updates existing, adds new)
- Fees/Salary: always appended as new payments
- Topics/Tasks/Internships: always added as new records

DATE FORMAT: YYYY-MM-DD (e.g. 2024-06-15)
COURSE STATUS VALUES: Pending | Continue | Complete | Leave | Left
EXISTING ACADEMY WORKBOOK BACKUP / RESTORE
===========================================

The supplied workbook "All Computer Care Academy Systems 2022-2027(Record and
Time Table).xlsx" can now be imported directly. No header renaming is needed.

Supported established tabs:
  - Student's Record (all 23 original columns, including Registration Number)
  - Teacher's Record

To restore: sign in as an Admin or Teacher, open Students or Reports, choose
Import from Excel, then select the workbook. Existing people are updated by
mobile number/name; new records are added. Student accounts are view/download
only. Teachers and admins can edit records.

To back up: choose Export Master Excel. The resulting workbook contains the
original-compatible Student's Record and Teacher's Record tabs first, plus the
website's optional data tabs (fees, attendance, timetable, notes, etc.).
